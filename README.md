##

### About

I build interfaces that feel fast and obvious to use. Most of my work sits where design meets engineering: taking a Figma file or a rough idea and shipping it as a product people can actually use, on any screen.

I care about the details users notice without knowing why: layouts that hold on every screen size, real loading, empty and error states, keyboard support, and code the next developer can read without a tour. I work async-first, ship in small reviewable steps, and keep clients in the loop with live previews instead of status reports.

##

### What I build

- **Web apps & dashboards**: admin panels, internal tools, client areas and SaaS front-ends in React + TypeScript, wired to real APIs, auth and databases.
- **Landing pages & websites**: product launches, portfolios and company sites. Responsive, SEO-ready and fast on mobile networks.
- **Design to code**: faithful builds from Figma, plus component libraries and design systems that keep a product consistent as it grows.
- **Interactive & 3D**: scroll-driven motion, micro-interactions and Three.js scenes that make a page memorable without making it slow.
- **Rescue & refactor**: taking over an existing front-end, fixing bugs and performance, migrating to TypeScript, and leaving it documented.

##

### How I work

1. **Brief**: you send the scope, a few references and your deadline. I reply with questions, a plan and a fixed quote.
2. **Design**: wireframes or a Figma pass for approval before any code, while changes are still cheap.
3. **Build**: frequent previews on a live URL, so you follow real progress, not promises.
4. **Launch**: deploy, domain, analytics and a handoff doc, plus a support window after go-live.

### Every project ships with

- Responsive layout tested on phones, tablets and desktop
- Accessibility basics: semantic HTML, keyboard navigation, readable contrast
- Performance budget: optimized images, code splitting, Lighthouse 90+
- Typed, linted code in a Git repository you own
- Deploy on Vercel, Netlify or your own server, with a README to run it
